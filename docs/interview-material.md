# CourseMind 面试讲解材料

## 一句话介绍

CourseMind 是一个面向 CityU 数据科学本科生的证据优先选课规划系统：把学生画像、官方课程规则、学期 AIMS 课表和社区体验组合起来，在硬约束校验通过后再生成可解释的课程建议。

## 核心链路

1. 用户在“我的”中保存分流、Catalogue Year、已修课程和偏好。
2. Router 判断课程事实、毕业规则、课表规划、课程比较或个性化规划意图。
3. 对课程和规则请求先检索官方 Catalogue；对排课请求先检索对应学期 AIMS 快照。
4. 确定性规则引擎校验先修课、分流权限、Section 限制、时间冲突和学分要求。
5. Planner 只对通过硬约束的候选课程做可解释排序；社区评价只作为软信号。

## 为什么不用 LLM 直接回答

课程规则和毕业要求属于高风险事实。LLM 可以负责理解问题和解释结果，但不能自行编造先修课、用社区评分覆盖官方规则，或把 AIMS 历史快照说成实时注册状态。

## AIMS 数据边界

当前系统使用用户导入的 Semester A 2026/27 快照，不保存 AIMS 凭据、不连接 AIMS、不执行注册。Section、CRN 和时间用于该学期规划；座位字段不参与排序，也不向用户展示。

## 评测回答

路由评测验证意图分类稳定性；证据评测验证官方来源是否命中；规则评测验证先修、权限、冲突和学分逻辑；端到端评测验证从输入画像到规划结果的完整链路。当前基线分别为 50/50、30/30、30/30 和 20/20。

## 当前不足与下一步

当前不足是三个课程当前页面正文仍受官网反爬影响、PDF 尚未完整入库、LLM provider 和前端尚未接入。下一步是补充可核验来源、接入真实模型适配层、增加持久化 trace，并完成前端联调。
