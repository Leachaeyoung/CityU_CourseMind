# CourseMind 评测与监控基线

## 离线评测

`evals/coursemind_cases.json` 是人工种子路由集，运行脚本会加入保持意图不变的措辞变体，形成 50 条离线回归样本，覆盖课程事实、课程比较、排课、毕业审计、个性化规划和澄清六类请求。`scripts/run_evidence_eval.py` 提供 30 条官方课程证据命中回归，`scripts/run_rule_eval.py` 提供 30 条规则回归，`scripts/run_planning_eval.py` 提供 20 条 Planner 端到端回归。它们仍是确定性专项回归，不等同于真实用户质量评测。

## 在线监控指标

- 路由：各 Intent 的准确率、澄清率、错误路由率。
- 证据：官方证据命中率、证据核验时间、无证据阻断率。
- 规则：先修/Section eligibility/时间冲突计算错误率。
- 规划：硬约束通过率、推荐后人工否决率、AIMS 数据新鲜度。座位余量暂不参与推荐排序，因为当前 AIMS 数据不是实时接口。
- 体验：回答延迟、用户对课程推荐的有用性评分、社区评价举报率。

监控中必须记录 `term_id`、`catalogue_year`、来源 URL 和数据核验时间；AIMS 快照过期时，系统应降级为“无法确认当前可注册性”，而不是继续生成确定结论。

当前提供 `GET /metrics` 作为本地监控出口，返回请求数、错误数、平均延迟、证据命中率和 AIMS 快照最新核验时间；不包含学生消息或个人信息。
